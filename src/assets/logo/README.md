# Thư mục Logo Cảnh Sát (PD Logo Assets)

Thư mục này dùng để lưu trữ logo của Sở Cảnh sát / Đơn vị Công an:
- `pd-logo.svg`: Logo định dạng vector sắc nét (khuyên dùng).
- `pd-logo.png`: Logo định dạng PNG trong suốt (khuyên dùng độ phân giải từ 256x256 trở lên).

### Hướng dẫn thay thế Logo:
1. Bạn có thể copy đè file logo thực tế của đơn vị vào đây với tên `pd-logo.svg` hoặc `pd-logo.png`.
2. Hoặc thay thế file `public/logo.png` và `public/logo.svg`.
3. Hệ thống sẽ tự động hiển thị logo ở:
   - Header thanh điều hướng
   - Màn hình đăng nhập
   - Favicon trình duyệt
   - Bảng kết quả in/xem chi tiết
